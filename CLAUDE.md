# HODOM

Repositorio centrado en la base de datos HODOM y su documentación vigente.
Este `CLAUDE.md` es la fuente de verdad documental del repo (`README.md` es un
puntero a este archivo).

## Alcance actual

- `db/`: artefactos versionados de la base PostgreSQL.
- `docs/`: modelo de datos, ERD, referencias normativas y estructura de reporting
  relacionada.

## Estado del repositorio

- No se mantienen pipelines de migración, dashboards, scripts operativos ni suites
  de pruebas.
- El repositorio conserva solo el estado actual de la base y la documentación
  necesaria para entenderla.

## Puntos de entrada

- [`db/README.md`](db/README.md) — inventario de los artefactos PostgreSQL
  versionados.
- [`docs/README.md`](docs/README.md) — índice documental vigente.
